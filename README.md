# Iberia Friday

This project was inspired from a LiDAR New article earlier this week that led me down a rabbit hole discovering Spain *Instituto Geografico Nacional* vast array of imagery and elevation data. To my delight, I discovered they have made three country-wide collections of aerial imagery and lidar over the past 20 years...and it's publicly available.  

Although it's publicly available, it's not as easy to discover as it could be.  Sure, it has a nice OGC Features API, some web services, but the remote sensing data is still behind their storage wall. It's not easily discoverable like a STAC API.  Looks like we'll have to search for some grids to help us get the lay of the land.  

At this point, I don't know what this project is.  My initial inspiration was to create my first JupyterBook.  Fridays are supposed to be my day, though I still work.  But now I'm going to set a little time aside every Friday to work on this *Iberia Friday* project.# iberia-friday
